# 📅 Моё расписание (Student Schedule Planner)

Современное, быстрое и ориентированное на приватность веб- и десктоп-приложение для студентов. Позволяет в один клик импортировать расписание из университетских файлов Excel (включая сложные формы СПбГУ, 1С и классические сетки), автоматически отфильтровать чужие подгруппы и элективы, вести заметки к парам и экспортировать события в календарь.

---

## ✨ Ключевые возможности

### 🧠 Умный импорт из Excel (`.xlsx`, `.xls`)
- **Автоматическое определение структуры**: понимает объединённые ячейки, заголовки дней недели, интервалы времени и строки продолжения (continuation rows).
- **Распознавание преподавателей и дисциплин**: специализированный эвристический алгоритм отделяет ФИО преподавателей и учёные звания (`доц.`, `проф.`, `ст. преп.`, `асс.`) от названий предметов и кратких наименований дисциплин.
- **Детекция типов занятий и аудиторий**: автоматически выделяет лекции, семинары, лабораторные, адреса корпусов и номера кабинетов.
- **Интерактивное превью**: предварительный просмотр распознанных занятий с подсветкой подгрупп перед добавлением в расписание.

### 🎯 Персонализация и фильтры
- **Фильтр подгрупп**: укажите свою подгруппу (например, `4` или `1-я`), и пары других подгрупп скроются автоматически.
- **Управление элективами**: скрытие чужих факультативов и предметов по выбору.
- **Личные события и заметки**: возможность добавлять свои дедлайны, консультации, тренировки и оставлять заметки к конкретным парам.
- **Цветовая кодировка**: визуальное разделение лекций, семинаров, практик и личных дел.

### 🖥️ Удобные режимы просмотра
- **Неделя (Week View)**: классическая сетка с наглядной раскладкой по парам и дням.
- **День (Day View)**: фокус на расписании на сегодня с таймлайном и текущим статусом.
- **Месяц (Month View)**: календарный обзор загруженности на месяц вперёд.
- **Список (Agenda View)**: компактный список всех предстоящих занятий с быстрым поиском.

### 🔒 Приватность (Local-First)
- **100% локальное хранение**: данные и файлы обрабатываются исключительно в вашем браузере/на компьютере (`localStorage`).
- Никакие файлы не отправляются на сторонние серверы или в облако.
- **Резервное копирование и синхронизация**:
  - Экспорт и импорт базы данных в формате JSON.
  - Экспорт в формат **iCalendar (`.ics`)** для интеграции с Google Календарём, Apple Calendar и Яндекс Календарём.

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org/) версии 18+ (рекомендуется 20+)
- Менеджер пакетов `npm`, `pnpm` или `yarn`

### Установка и запуск веб-версии

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
   cd schedule-app
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите режим разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

## 💻 Сборка десктопного приложения (Tauri)

Для сборки нативного приложения для Windows (`.msi` / `.exe`), macOS (`.dmg`) или Linux (`.deb` / `.AppImage`):

1. Убедитесь, что установлен [Rust](https://www.rust-lang.org/tools/install).
2. Запустите в режиме разработки Tauri:
   ```bash
   npm run tauri:dev
   ```
3. Соберите релизный бинарный пакет:
   ```bash
   npm run tauri:build
   ```
